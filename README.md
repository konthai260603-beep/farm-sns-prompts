# Farm SNS Prompt Kit 🌱

농부와 소규모 농가를 위한 무료 AI 홍보 프롬프트 모음입니다.
ChatGPT와 Claude에서 사용할 수 있습니다.

## 1. 인스타그램 홍보글 만들기

아래 프롬프트를 복사해 사용하세요.

```
우리 농산물을 소개하는 인스타그램 게시글을 작성해 줘.

지역: [지역 입력]
농산물: [품목 입력]
특징: [맛, 재배 방식 등 실제 특징]
판매 방식: [직거래, 택배 등]

조건:
- 친근하고 자연스러운 말투
- 150자 내외
- 해시태그 5개
- 과장된 표현 금지
- 제공하지 않은 정보는 만들어내지 않기
```

## 2. 농산물 홍보 이미지 만들기

농산물 사진을 첨부하고 아래 프롬프트를 사용하세요.

```
첨부한 농산물을 인스타그램 홍보용 연출 사진으로 만들어 줘.

- 원래 농산물의 품종, 색상, 형태 유지
- 자연광이 들어오는 농장 또는 나무 테이블 배경
- 신선하고 먹음직스러운 사진 스타일
- 세로형 3:4 비율
- 텍스트와 워터마크 없음
```

## 사용 방법

1. 프롬프트를 복사합니다.
2. 대괄호 안에 우리 농장 정보를 입력합니다.
3. ChatGPT 또는 Claude에 붙여 넣습니다.
4. 생성된 내용을 확인하고 수정해 게시합니다.
